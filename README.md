# Lab 2: Web & DNS Server Security (Packet Tracer)

A small LAN built in Cisco Packet Tracer with a DNS server and a web server, then secured against common attacks.

## What it demonstrates
- DNS name resolution and web hosting (`tech4youth.com`)
- Packet flow analysis in Simulation Mode (ARP, DNS, HTTP)
- Moving from HTTP to HTTPS to stop plaintext snooping
- Switch port security with sticky MAC addresses
- A rogue-device test: the switch shuts the port (err-disabled) and an admin recovers it

## Files
| File | Description |
|---|---|
| `Lab2_Report.pdf` | Full write-up with screenshots and answers |

## Open the project
1. Install Cisco Packet Tracer (9.0.1 was used).
2. Download `lab2-assignment.pkt` and open it.

## Notes
- DNSSEC and DNS zone transfer settings are not supported in Packet Tracer, so they are covered in the report only.

*Built for learning in a simulated environment only.*
